## 📝 Project Overview

The CS-Cart Auction Add-on enables online stores to run product auctions where customers can place bids and compete to purchase products. The add-on supports both incremental and decremental auction types, allowing store owners and vendors to manage auctions, bidding, timings, and winners from the platform.

---

## ✨ Key Features

- Enable auctions for products
- Support incremental and decremental bidding
- Set auction start and end times
- Configure starting, reserve, and bid prices
- Manage bid history
- Send email notifications to bidders
- Allow admins and vendors to manage auctions
- Declare auction winners
- Provide a Buy Now option
- Customize the auction view
